# Эмулятор оболочки ОС

## Общее описание
GUI-эмулятор командной строки UNIX-подобной ОС на Python (tkinter).
Реализован этап 1: REPL.

## Описание функций и настроек
- `make_title()` - заголовок окна `Эмулятор - [user@host]`.
- `parse_line(line)` - разбор строки на команду и аргументы.
- `execute(line)` - выполнение команды, возвращает текст ответа.
- Команды: `ls`, `cd` (заглушки, печатают имя и аргументы), `exit`.
- Ошибки: `команда: команда не найдена`, `cd: слишком много аргументов`,
  `exit: неверные аргументы`.

## Сборка и тесты
Нужен Python 3 с tkinter (в Linux: `sudo apt install python3-tk`).

```
make run     # запуск (или ./run.sh, или run.bat на Windows)
make test    # запуск тестов
```

## Примеры использования
```
$ ls -l /tmp
ls -l /tmp
$ cd a b
cd: слишком много аргументов
$ foo
foo: команда не найдена
$ exit
```
