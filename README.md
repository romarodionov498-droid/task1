# Эмулятор оболочки ОС

## Общее описание
GUI-эмулятор командной строки UNIX-подобной ОС на Python (tkinter).
Реализованы этапы 1-3: REPL, конфигурация и виртуальная файловая система.

## Описание функций и настроек
- `make_title()` - заголовок окна `Эмулятор - [user@host]`.
- `parse_line(line)` - разбор строки на команду и аргументы.
- `execute(line, vfs)` - выполнение команды, возвращает текст ответа.
  При ошибке выбрасывает `ShellError`.
- `parse_args(argv)` - разбор параметров командной строки.
- `debug_lines(args)` - отладочный вывод заданных параметров.
- `strip_comment(line)` - удаление комментария из строки скрипта.
- `read_script(path)` - чтение стартового скрипта.
- `load_vfs(path)` - загрузка VFS из JSON-файла в память.
- `count_nodes(node)`, `tree_lines(node)` - подсчёт и вывод дерева VFS.

Команды:
- `ls`, `cd` - заглушки, печатают имя и аргументы.
- `exit` - завершить эмулятор.
- `vfs` - служебная команда, показывает дерево загруженной VFS.

Параметры командной строки:
- `--vfs ПУТЬ` - путь к JSON-файлу с VFS.
- `--script ПУТЬ` - стартовый скрипт: одна команда на строку, комментарии
  начинаются с `#`. Ввод и вывод показываются в окне, ошибочные строки
  пропускаются с сообщением об ошибке.
- При запуске выводятся отладочные строки `[debug]` со всеми параметрами.

Формат VFS (JSON). Все данные хранятся только в памяти, на диск ничего
не распаковывается. Узел - папка или файл:
```
{"type": "dir", "children": {"имя": узел, ...}}
{"type": "file", "content": "текст"}
{"type": "file", "encoding": "base64", "content": "SGVsbG8="}
```
Двоичные файлы записываются строкой base64.

Ошибки: `команда: команда не найдена`, `cd: слишком много аргументов`,
`exit: неверные аргументы`, `vfs: VFS не загружена`, а также ошибки
загрузки VFS (нет файла, неверный JSON, неверный base64).

## Сборка и тесты
Нужен Python 3 с tkinter (в Linux: `sudo apt install python3-tk`).

```
make run     # запуск (или ./run.sh, или run.bat на Windows)
make test    # запуск тестов
```

Скрипты реальной ОС лежат в папке `tests` (файлы `demo_*.bat`),
примеры VFS - в `tests/data`, скрипты эмулятора - в `tests/scripts`.
Главный тест всех команд: `tests\demo_full.bat`.

## Примеры использования
```
$ ls -l /tmp
ls -l /tmp
$ cd a b
cd: слишком много аргументов
$ foo
foo: команда не найдена
$ vfs
/
  etc/
    config.txt (текст, 7 байт)
  home/
    user/
      docs/
        photo.bin (двоичный, 8 байт)
        report.txt (текст, 10 байт)
      todo.txt (текст, 21 байт)
$ exit
```

Запуск с параметрами:
```
python src\emulator.py --vfs tests\data\deep.json --script tests\scripts\full.txt
```
